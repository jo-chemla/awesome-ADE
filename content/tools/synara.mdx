Synara is a local-first desktop workspace that wraps the coding-agent CLIs you already have installed. Each project holds threads; each thread pairs an agent session with workspace surfaces (diffs, terminal, browser with WebMCP, files/editor, git/PRs). Managed worktrees isolate parallel threads, handoffs move a thread to a different provider, and automations schedule recurring agent runs.
