An agentic development environment grown out of a terminal. Use its built-in agent, paid with Warp credits or your own API key (a Claude subscription can't power it), or run CLI agents such as Claude Code, Codex or OpenCode in its panes. Those CLI sessions don't appear in Warp's agent panels.

Its star count isn't directly comparable with the rest of this list. The repo dates from 2021 but its code only went public on 2026-04-28: about 26k stars came before that, and about 26k more in that one week.
