cmux is a native macOS terminal designed around running many CLI agents in parallel: notification rings on panes needing attention, a sidebar with per-agent metadata, a programmable browser pane agents can use to verify web changes, and session restore. It uses libghostty for rendering and reads your Ghostty config.
