OpenCode is the open-source coding agent itself (not a wrapper around other CLIs), with a TUI, IDE extensions, a web UI and a beta desktop app. It works with 75+ model providers, and as of 2026-10-29 again supports Claude subscriptions, with the OpenCode team stating it has Anthropic's permission ([PR #58782](https://github.com/anomalyco/opencode/pull/58782)).
