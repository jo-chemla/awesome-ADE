Automaker is an open-source autonomous AI development studio built around a feature/Kanban workflow. Agents implement tasks in isolated git worktrees with real-time streaming, plan approval, testing, and review workflows. It supports Claude, Codex, Copilot, Cursor, Gemini, and OpenCode providers.

Note: the repository currently states that the project is no longer actively maintained.
