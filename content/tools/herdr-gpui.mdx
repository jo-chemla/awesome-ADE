Herdr UI is an unofficial native client for the [herdr](https://herdr.dev/) daemon (`herdr server`, the engine behind the herdr TUI), not affiliated with the herdr team and separate from their own [Herdr app](https://github.com/herdrdev/herdr-app). It paints the daemon's terminal cells directly instead of wrapping the TUI. On top it adds a Review Changes tab where you leave PR-style notes on an agent's diff and send them back to that agent, browser tabs with element annotations agents can open, plan-usage meters for signed-in AI services, and macOS Dock or Windows taskbar badges when an agent needs you.
