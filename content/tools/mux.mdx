Xum (renamed from Mux in 2026) is Coder's open-source coding-agent multiplexer: a desktop and browser application for planning and executing work with multiple AI agents in parallel. It supports local directories, isolated git worktrees, and remote SSH execution, with a custom agent loop and multi-model support.
