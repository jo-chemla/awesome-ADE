Ovis (formerly the herdr web UI) is the cross-device client for [herdr](https://github.com/herdrdev/herdr): the same agents that the Herdr app drives from a desktop multiplexer, viewed here as chats on desktop, phone or browser. Agents run on your own machine; Ovis adds tappable prompt/approval cards, push notifications, a one-click live terminal and a unified workspace list spanning local and SSH machines. Phones connect through an optional E2E-encrypted relay (the relay can't read traffic), Tailscale, a VPN or an SSH tunnel. Built with TypeScript/React on Bun, xterm.js and a Rust PTY sidecar. Anonymous usage counts are on by default and can be disabled in Settings or with `OVIS_TELEMETRY=0`. A browser demo lives at [ovis.sh/demo](https://ovis.sh/demo).
