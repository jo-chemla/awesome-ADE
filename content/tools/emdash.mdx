Emdash is a local-first desktop app for running AI coding agents in parallel. It supports Claude Code, Codex, Cursor, OpenCode, Amp, Devin, Qwen Code, Droid, GitHub Copilot, and other provider CLIs, with worktree isolation, diff/PR/CI workflows, issue ingestion, and SSH/SFTP remote projects.
