omg.dev turns your machine into an always-on host for coding agents. It runs Claude Code, Codex, OpenCode, Cursor, Grok, Copilot, and Pi in tmux-backed sessions that persist across disconnects, with an MCP-based delegation system for spawning and tracking subagents. Access is via a browser/PWA or SSH, over Tailscale or an outbound-only relay.
