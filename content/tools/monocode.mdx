MonoCode is a Tauri desktop GUI for Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, Pi, omp, fx, Hermes Agent and Devin, using the subscriptions you already have (it does not sell tokens). Sessions are tabs, worktrees isolate parallel tasks, and an `/operator` mode lets an agent orchestrate other sessions. A separate [monocode-server](https://github.com/visualfusion/monocode-server) project provides a hardened containerized remote host.
