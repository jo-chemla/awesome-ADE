Desktop GUI from the herdr team, built on the new herdr-core runtime (`hc`) rather than the herdr TUI engine. Every part of the window is a file: layouts and JavaScript mods draw panels, menus and dialogs, so you can ask your agent to change the app itself. herdr-core lets agents start other agents, send them work and hear back, with status reported through the OSC 7501 Program Status Protocol.
